# PulseIQ Dataset Pack

The *_demo.csv files are SYNTHETIC portfolio data. They are intended for AWS pipeline development,
dashboard demos, API testing, streaming demonstrations and end-to-end integration.

For genuine ML training/evaluation, pair these with public labeled NLP datasets. Keep public training
data separate from the synthetic PulseIQ application/demo data.

Files:
- customer_feedback_demo.csv — 20,000 records
- employee_feedback_demo.csv — 8,000 records
- risk_complaints_demo.csv — 15,000 records
- aspect_sentiment_demo.csv — 3,000 records
- streaming_feedback_events.csv — 1,000 records
- aspect_taxonomy.csv
- intent_taxonomy.csv
- emotion_taxonomy.csv
- employee_topic_taxonomy.csv
